# Венера

[English](./README.md) · **Русский**

![Венера](docs/img/image.png)

**Венера — сердце проекта.**

В сердце живут чувства, любовь, желания, оценки — куда вы хотите прийти и почему. А ещё эстетика, чувство прекрасного. Оно гоняет эмоции и чувства. В телесном плане, сердце гоняет кровь, чтобы тело работало.

Венера делает то же для проекта: **накапливает** чувства и желания (цели, намерения, спецификацию, которую принимают люди). **Гонит спецификации как кровь** через полный цикл — план, реализация, тесты, ревью, итерация — чтобы остальное тело (агенты, PR, код, ревью, тесты, публикации) могли работать. Без этого пульса цикл — работа без сердца.

**Люди сохраняют сердечность, инстинкт, веру и целеполагание, а агенты делают работу.**

Это и есть продукт. Венера — сердце проекта, не доска и не агент. Вики, агентные чаты, ревью, планы, код и публикации — это тело, поддерживаемое пульсом желаний, а не то, что нужно любить.

## На практике

**Венера — инструмент spec-driven development:** совместная вики, которая одновременно является деревом markdown в git, покрытое семантическим графом с историческим измерением. Спецификация — фундамент, цели и рамки проекта. Но ничего не установлено целью, пока человек не принял diff спецификации.

## Запуск

Node `>=22`, pnpm `10.19.0`. Из корня репозитория:

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

Что делают команды, что покрывает Vitest и что ещё не автоматизировано: **[docs/runbook.md](docs/runbook.md)**. Каталог тестов: **[docs/scenarios](docs/scenarios/README.md)**. Compose / позже Kubernetes: **[docs/devops](docs/devops/README.md)**.
